# Workspace & File Organization Rules

- **Zero Desktop Clutter**: NEVER write files directly onto the Desktop (`~/Desktop/`). All scripts, utilities, tools, and output files must be placed inside an organized dedicated subfolder.
- **Dedicated Subfolders Required**: Whenever writing any file or script, always create or place it inside a meaningful subfolder (e.g. `~/Desktop/<ToolName>/`, `~/Tools/<ToolName>/`, or inside a structured project subdirectory).
- **User Override**: If the user explicitly asks to save to a specific path (including Desktop or the workspace root), follow the user's path.
- **Logical Directory Structure**: Maintain clean project structure (`scripts/`, `src/`, `output/`, `docs/`) and avoid placing loose files in the root folder.
